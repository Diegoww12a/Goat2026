# GOAT — Site da Plataforma Competitiva

Site institucional da plataforma competitiva **GOAT**, dedicada a campeonatos de GTA/FiveM.

![Prévia](https://raw.githubusercontent.com/Diegoww12a/Goat2026/main/docs/preview.png)

**Demonstração:** https://goatbattleroyalefake2026.netlify.app/

## Sobre

Portal completo da comunidade: história do projeto, sistema de ranqueamento, loja de itens e área de planos premium.

## Seções

| Seção | Conteúdo |
|---|---|
| **Home** | história do GOAT, diferencial, visão e "como jogar" |
| **Descobrir** | ranking de temporada com K/D, abates, vitórias e rating |
| **Perfil** | ficha detalhada do jogador com estatísticas |
| **Loja** | catálogo com busca, filtro por categoria e modal de produto |
| **Squad** | ranking de squad e janela de inscrições |
| **Planos** | planos premium com benefícios |

## Stack

| Camada | Tecnologia |
|---|---|
| Interface | React + Vite |
| Estilos | Tailwind CSS + PostCSS |
| Ícones | Font Awesome · Tabler Icons |
| Tipografia | Fontsource (DM Sans, Figtree, Geist, Inter, JetBrains Mono, Bebas Neue…) |
| Lint | ESLint |

## Rodar localmente

```bash
git clone https://github.com/Diegoww12a/Goat2026.git
cd Goat2026/siteReact
npm install
npm run dev
```
